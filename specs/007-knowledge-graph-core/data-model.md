# Data Model: Knowledge Graph Core Components

**Feature**: 007-knowledge-graph-core

This document defines the core data structures for facts, the ingestion queue, and the working memory.

## 1. `Fact`

The fundamental unit of knowledge, representing a subject-predicate-object triple with metadata.

### Class Definition

- **Type**: Pydantic Model (v2)
- **Immutability**: Frozen (`ConfigDict(frozen=True)`) to ensure consistency after creation.

### Fields

| Field | Type | Description | Constraints |
| :--- | :--- | :--- | :--- |
| `subject` | `str` | The subject of the RDF triple. | URI or identifier. |
| `predicate` | `str` | The predicate (relationship) of the RDF triple. | URI or identifier. |
| `object` | `str` | The object of the RDF triple. | URI, identifier, or literal value. |
| `id` | `str` | A unique identifier for the fact, generated by hashing its canonical string representation. | Automatically generated. |
| `createdAt` | `datetime` | Timestamp of when the fact was created. | Automatically generated. |
| `source` | `str` | Provenance of the fact (e.g., "user", "inferred", "system"). | |

### Methods

- `serialize_canonical() -> str`: Returns a canonical string representation of the `(subject, predicate, object)` for consistent hashing.
- `generate_id() -> str`: Generates the `id` field using a hash (e.g., SHA256) of the canonical string.

## 2. `IFactQueue`

An abstract interface for fact ingestion queues.

### Abstract Class Definition

- **Type**: Python Abstract Base Class (`abc.ABC`)

### Abstract Methods

| Method | Signature | Description |
| :--- | :--- | :--- |
| `enqueue` | `async def enqueue(self, fact: Fact)` | Adds a single fact to the queue. |
| `dequeue_batch` | `async def dequeue_batch(self, size: int) -> List[Fact]` | Retrieves a batch of facts from the queue. |

## 3. `MemoryFactQueue`

An in-memory implementation of `IFactQueue`.

### Class Definition

- **Type**: Concrete Python Class

### Internal State

- `_queue`: `asyncio.Queue` (stores `Fact` objects)
- `_seen_fact_ids`: `Set[str]` (stores IDs of facts currently in the queue to prevent duplicates)
- `_lock`: `asyncio.Lock` (protects `_seen_fact_ids` from race conditions)

## 4. `IFactHandler`

An abstract interface for components that process batches of facts.

### Abstract Class Definition

- **Type**: Python Abstract Base Class (`abc.ABC`)

### Abstract Methods

| Method | Signature | Description |
| :--- | :--- | :--- |
| `handle` | `async def handle(self, batch_of_facts: List[Fact])` | Processes a batch of facts. |

## 5. `FactDispatcher`

Orchestrates fact processing by dequeuing from `IFactQueue` and distributing to `IFactHandler` subscribers.

### Class Definition

- **Type**: Concrete Python Class

### Internal State

- `_fact_queue`: `IFactQueue` (the queue to monitor)
- `_handlers`: `List[IFactHandler]` (registered subscribers)
- `_batch_size`: `int` (number of facts to dequeue at once)
- `_polling_interval`: `float` (time to wait between queue checks)

### Methods

| Method | Signature | Description |
| :--- | :--- | :--- |
| `register_handler` | `def register_handler(self, handler: IFactHandler)` | Registers a new fact handler. |
| `start_dispatching` | `async def start_dispatching(self)` | Starts the infinite loop to monitor the queue and dispatch facts. |

## 6. `MemoryNode`

Represents an item (Fact or Rule) within the `AttentionGraph` (working memory), tracking its activation level.

### Class Definition

- **Type**: Concrete Python Class

### Fields

| Field | Type | Description | Constraints |
| :--- | :--- | :--- | :--- |
| `item` | `Union[Fact, Any]` | The underlying `Fact` or `Rule` object. (`Rule` to be defined later if needed) | |
| `activation_level` | `float` | The current activation level of the node. | `0.0 <= level <= 1.0` |
| `last_accessed` | `datetime` | Timestamp of the last time this node was accessed or stimulated. | |

## 7. `AttentionGraph`

Manages the collection of `MemoryNode`s, representing the system's working memory.

### Class Definition

- **Type**: Concrete Python Class

### Internal State

- `_nodes`: `Dict[str, MemoryNode]` (maps fact/rule ID to `MemoryNode`)

### Methods

| Method | Signature | Description |
| :--- | :--- | :--- |
| `add_node` | `def add_node(self, item: Union[Fact, Any])` | Adds a new Fact or Rule to the graph as a `MemoryNode`. | |
| `stimulate` | `def stimulate(self, item_id: str, amount: float)` | Increases the activation level of a node. | Amount > 0, capped at 1.0. |
| `decay` | `def decay(self, factor: float)` | Reduces the activation level of all nodes. | `0.0 <= factor < 1.0` |
| `prune` | `def prune(self, threshold: float)` | Removes nodes with activation below a threshold. | `0.0 <= threshold < 1.0` |
| `get_active_subgraph` | `def get_active_subgraph(self) -> List[Union[Fact, Any]]` | Returns the underlying items of nodes with activation above a threshold. | |
