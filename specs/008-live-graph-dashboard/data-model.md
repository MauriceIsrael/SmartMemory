# Data Model: Live Graph Updates

**Feature**: 008-live-graph-dashboard

This document outlines the data structures used for communicating real-time graph changes from the backend to the frontend.

## 1. `GraphUpdateEvent`

This is the primary data structure sent from the server to the client over the Server-Sent Events (SSE) stream.

- **Description**: Represents a single change in the knowledge graph, typically the addition of a new fact.
- **Format**: JSON

### Fields

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `type` | String | The type of event that occurred. Initially, this will be `fact_added`. | `"fact_added"` |
| `data` | Object | A nested object containing the details of the new fact. | `{...}` |

---

## 2. `FactData`

The `data` field of the `GraphUpdateEvent` will contain an object with this structure. It represents the fact that was added.

### Fields

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `subject` | String | The subject of the triple. | `"http://example.com/User/1"` |
| `predicate` | String | The predicate of the triple. | `"http://xmlns.com/foaf/0.1/knows"` |
| `object` | String | The object of the triple. Can be a literal or a URI. | `"http://example.com/User/2"` |
| `metadata` | Object | An object containing metadata about the fact. | `{...}` |

---

## 3. `FactMetadata`

The `metadata` field of the `FactData` object.

### Fields

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `id` | String | The unique hash/ID of the fact. | `"abc123def456"` |
| `is_inferred` | Boolean | `true` if the fact was generated by the inference engine, `false` if it was explicitly added by a user. | `true` |

## Example SSE Message

The server will send messages over the `text/event-stream` that look like this:

```
event: graph_update
data: {
data:   "type": "fact_added",
data:   "data": {
data:     "subject": "http://example.com/User/1",
data:     "predicate": "http://xmlns.com/foaf/0.1/knows",
data:     "object": "http://example.com/User/2",
data:     "metadata": {
data:       "id": "abc123def456",
data:       "is_inferred": true
data:     }
data:   }
data: }
```
