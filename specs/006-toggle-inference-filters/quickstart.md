# Quick Start: Manage Inference Engines and Filters

This guide explains how to use the new feature for managing inference engines.

## 1. Backend Setup

1.  Navigate to the `supervision_backend` directory.
2.  Install dependencies: `pip install -r requirements.txt`.
3.  Run the backend server: `python main.py` (or similar command).

The backend now exposes new API endpoints for managing inference engines.

## 2. Frontend Setup

1.  Navigate to the `supervision_frontend` directory.
2.  Install dependencies: `npm install`.
3.  Run the development server: `npm run dev`.

## 3. Using the Feature

### Toggling Inference Engines

1.  Open the application in your browser and navigate to the **Administration Console**.
2.  You will see two new toggle switches labeled **"OWL-RL Engine"** and **"SPARQL Engine"**.
3.  Clicking a toggle will enable or disable the corresponding engine. The backend will load/unload the associated rules, and the state will be persisted.

### Filtering Rules and Facts

1.  Navigate to the **Rule Management** page.
2.  Click the "Filter" button and select **"Dynamically Loaded"**. The list will update to show only the rules that were loaded by an active inference engine.
3.  Navigate to the **Facts** page.
4.  Click the "Filter" button and select **"Inferred"**. The list will update to show only the facts that were generated by an active inference engine.

## 4. API Endpoints

This feature introduces the following API endpoints:

-   `GET /api/inference-engines`: Lists the state of the inference engines.
-   `POST /api/inference-engines/{engine_name}`: Updates the state of an engine.
-   `GET /api/rules?source={source}`: Filters the rules list.
-   `GET /api/facts?origin={origin}`: Filters the facts list.

Refer to the `contracts/openapi.yml` file for detailed API documentation.
