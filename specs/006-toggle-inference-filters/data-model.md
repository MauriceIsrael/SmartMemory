# Data Model: Manage Inference Engines and Filters

This document outlines the key data entities for the feature, based on the `spec.md`.

## 1. Inference Engine State

Represents the configuration state of a single inference engine.

-   **`name`**: `string`
    -   Description: The unique identifier for the engine.
    -   Constraints: Primary Key. Must be one of "OWL-RL Engine" or "SPARQL Engine".
-   **`is_enabled`**: `boolean`
    -   Description: The current state of the engine. `true` if active, `false` otherwise.
    -   Default: `false`.
-   **`description`**: `string`
    -   Description: A brief, human-readable description of the engine's purpose.

**Example**:
```json
{
  "name": "OWL-RL Engine",
  "is_enabled": true,
  "description": "Handles OWL-RL based inferences."
}
```

## 2. Rule

Represents a single inference rule in the system.

-   **`id`**: `string`
    -   Description: A unique identifier for the rule.
-   **`content`**: `string`
    -   Description: The actual body of the rule (e.g., a SPARQL CONSTRUCT query).
-   **`source`**: `string (enum)`
    -   Description: The origin of the rule.
    -   Values:
        -   `default`: The rule is part of the system's core rule set and is always loaded.
        -   `dynamic`: The rule was loaded dynamically as a result of an administrator enabling an inference engine.

**Example**:
```json
{
  "id": "spouses_know_each_other",
  "content": "CONSTRUCT { ?p1 foaf:knows ?p2 } WHERE { ?p1 schema:spouse ?p2 }",
  "source": "dynamic"
}
```

## 3. Fact

Represents a single triple in the knowledge graph.

-   **`triple`**: `string`
    -   Description: A string representation of the Subject-Predicate-Object triple.
-   **`origin`**: `string (enum)`
    -   Description: The origin of the fact.
    -   Values:
        -   `explicit`: The fact was provided directly by a user or external source.
        -   `inferred`: The fact was generated by one of the inference engines.

**Example**:
```json
{
  "triple": ":Gilles foaf:knows :Daniel",
  "origin": "inferred"
}
```
