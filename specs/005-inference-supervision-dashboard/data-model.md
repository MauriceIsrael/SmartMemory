# Data Model: Inference Supervision Dashboard

This document outlines the key data entities for the Inference Supervision Dashboard, based on the feature specification.

## 1. Fact (Triplet)

Represents a single atomic piece of information in the knowledge graph.

*   **Fields**:
    *   `Subject`: `string` - The entity the fact is about.
    *   `Predicate`: `string` - The property or relationship of the fact.
    *   `Object`: `string` - The value or other entity related by the predicate.
    *   `Provenance`: `string` - The source of the fact (e.g., "user" for asserted facts, or the ID of the rule for inferred facts).
*   **Relationships**:
    *   Implicitly related to other Facts through shared Subjects, Predicates, or Objects.

## 2. Inference Rule

Represents a SPARQL rule used by the inference engine to generate new facts.

*   **Fields**:
    *   `id`: `string` (unique identifier) - The unique ID of the rule.
    *   `description`: `string` - A human-readable description of the rule's purpose.
    *   `sparql_query`: `string` - The full SPARQL CONSTRUCT query.
    *   `is_active`: `boolean` - The current state of the rule (true for active, false for inactive).
    *   `execution_count`: `integer` - The number of times the rule has been executed.
    *   `triples_generated`: `integer` - The total number of triplets generated by this rule.
    *   `validation_error`: `string` (nullable) - Any validation errors associated with the rule.
*   **State Transitions**:
    *   The `is_active` state can be toggled between `true` and `false` by a user action.

## 3. System Stats

A composite object representing the overall health and state of the `SmartMemory` system.

*   **Fields**:
    *   `total_triplets`: `integer` - Total number of triplets in the graph.
    *   `inferred_triplet_count`: `integer` - Number of triplets generated by inference rules.
    *   `asserted_triplet_count`: `integer` - Number of triplets added manually.
    *   `active_rule_count`: `integer` - Number of currently active rules.
    *   `inactive_rule_count`: `integer` - Number of currently inactive rules.

## 4. Log Entry

Represents a single log message from an inference run.

*   **Fields**:
    *   `timestamp`: `datetime` - The time the log message was generated.
    *   `level`: `string` - The log level (e.g., INFO, WARNING, ERROR).
    *   `message`: `string` - The log message content.
