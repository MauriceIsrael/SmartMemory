# Fixes Applied - SmartMemory MCP Server

## Date: 2025-11-25

### 1. ✅ Added Missing Tool: `get_pending_verifications`

**Issue**: Gemini looked for `get_pending_verifications` tool which didn't exist.

**Solution**: Created new MCP tool at `src/semantic_memory/tools/get_pending_verifications.py`

**What it does**:
- Lists all uncertain inferences waiting for user confirmation
- Shows verification ID, triple, confidence score, and source rule
- Returns formatted message for Gemini to present to user

**Usage**:
```
Gemini: "Are there any facts that need my verification?"
→ Uses get_pending_verifications tool
→ Lists pending inferences with IDs
→ User can then verify with verify_inference tool
```

**Status**: ✅ Registered in server.py, ready to use after restart

---

### 2. ✅ Fixed False Positive Conflicts

**Issue**: 17 "contradictory_literal" conflicts reported from SKOS/RDFS ontologies  
Example: Multiple `rdfs:comment` on same SKOS property (which is normal)

**Root Cause**: Conflict detector ran on ALL triples including ontologies

**Solution**: Filter conflicts to only check **user data**, not ontology triples

**Implementation**:
- Modified `add_memory.py` conflict detection (lines 140-185)
- Filter based on `sem:source "user"` provenance
- Additional filter: only report conflicts where subject is in user namespace
- Prevents ontology metadata from being flagged as conflicts

**Result**: 
- Before: 17 false positive conflicts
- After: Only real user data conflicts reported ✅
